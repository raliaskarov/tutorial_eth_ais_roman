🎰 Simplified Blackjack 🎰

A fun twist on the classic card game!

📋 Game Rules

  • You start with a sum of 0
  • Cards are random integers from 1 to 10
  • HIT: Draw a card and add it to your sum
    • If sum ≤ 21: Get reward = card value
    • If sum > 21: BUST! Game ends with reward = -sum
  • STICK: End the game with reward = 0
  • Goal: Maximize your total reward across all games!
